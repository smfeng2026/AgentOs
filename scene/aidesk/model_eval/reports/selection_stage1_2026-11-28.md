# 阶段一选型报告 — 端侧模型 zero-shot 能力基线（2026-11-28）

## 实验设置

- 数据：`approved_all_v1`，48 条人工批准样本（审批人 sumi），快照 sha256 见 datasets/approved_all_v1/SOURCE.md。
- 条件：Apple M5 / MPS / float16，贪心解码，max_new_tokens 3000，system prompt 为 6h SFT 同款（sha256 钉在各 run.json）。
- 权重：官方 HF 仓库，revision 钉死（qwen3 c1899de2 / lfm2.5 9921cd4d / mnn-pocket 48fae9c0）。
- 评测：6h 评测器，意图按证据集 Jaccard ≥ 0.4 匹配。

## Prompt 消融（Qwen3，富 prompt vs 原 prompt）

补全枚举 + 全覆盖强约束 + 示例后：漏标 76%→39%、关系 F1 0.213→0.339、category/status 遵循 0.25→0.667、grounding 0.125→0.67；
但原始格式率 72.9%→18.8%（长输出诱发重复循环，21 条撞 3000 上限），purpose 从自由文本变为全 unknown（过度矫正）。
**结论：prompt 能修复覆盖与词表遵循，但 0.6B 基座对长 prompt 脆弱；富 prompt 不采纳为部署 prompt，SFT 仍是主路径。**

## 判断

1. 三模型均远低于设计目标线，**zero-shot 不可用，必须 SFT**。
2. Qwen3-0.6B 是唯一产出证据关联的模型，且微调生态最成熟 → **阶段二 SFT 主力候选**。
3. LFM2.5-350M 格式最稳但证据「空心」→ 保留为架构对照候选，观察其可训练性。
4. MNN-Pocket-0.3B 生成式 schema 遵循崩溃 → 生成任务降级；其 Dec（非自回归决策）变体可另做事件分类专项。
5. 地板附近绝对值噪声大，SFT 后排序可能变化；本报告只约束阶段一。

## 局限

- n=48，类别切片每类 2–4 条，切片结论仅供方向参考。
- MPS/fp16 为服务端能力条件，非真机部署效率（阶段三另测）。
- 评测器渲染 None 防护已修复（evaluator.py render_markdown，45 测试通过）；指标逻辑未动。
